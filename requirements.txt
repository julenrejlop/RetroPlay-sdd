Node.js >= 18.0.0 (probado con v24.15.0)
npm >= 9.0.0 (probado con 11.12.1)
Docker Desktop / Docker Engine >= 20.10 con Docker Compose v2
Navegador web moderno con soporte JavaScript y HTML5 Audio/Video
Conexión a Internet para la inserción y reproducción de vídeos de YouTube
